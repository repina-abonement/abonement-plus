# Абонемент Плюс — версия 0.1 (тестовая)

CRM для детской спортивной школы: воронки, ученики и семьи, журнал посещений,
абонементы с расчётом цены, отпуска, пропуски и отработки.

Работает на чистом Python 3.11+ без внешних пакетов. База — SQLite.

## Что умеет

- **Воронка продаж** (канбан, перетаскивание): лид → недозвон → записан на пробное →
  напоминание → *сейчас на пробном* (сама) → *пробное закончилось* (сама, жёлтая
  через 30 мин, красная через час) → как прошло → купил / отказ.
- **Ученики и продления**: этапы ставятся сами по оплатам. Не продлившие после 25 числа — красные.
- **Пропуски**: ученики с неотработанными пропусками за этот и прошлый месяц.
- **Карточка ученика**: семья и родители, братья и сёстры, группа, тариф, счётчик пропусков
  и отработок, расчёт абонемента, отпуск, история.
- **Абонемент на месяц** = занятия группы в месяце (без отпуска) × цена занятия.
  Гибкий тариф: минус до 3 неотработанных пропусков прошлого месяца; использованные
  пропуски обнуляются. Наценка за оплату после 25 числа — включается в настройках.
- **Журнал**: отметки «был / пропуск». Тренер видит только свои группы и не видит телефонов.
- **Отработки**: по субботам на Небе, 14:00 (3–5 лет) и 15:00 (6–8 лет).
- **Сотрудники и роли**: админ, оператор, тренер. Журнал действий, резервная копия раз в сутки.

Пока нет: оплата по СБП и чеки 54-ФЗ, мессенджеры, телефония, ИИ-помощник, отчёты,
перенос из ERP. Это следующие этапы.

## Запуск у себя

```
python3 -m crm.server          # http://127.0.0.1:8000
python3 -m tests.test_crm      # проверка правил абонементов
```

Пароль администратора задаётся переменной `CRM_ADMIN_PASSWORD`, иначе генерируется
и печатается при первом запуске. `CRM_DEMO=1` добавляет выдуманных клиентов для теста.

## Запуск на сервере

Ubuntu 24.04. В консоли сервера под root:

```
curl -fsSL https://raw.githubusercontent.com/repina-abonement/abonement-plus/main/deploy/install.sh | bash
```

Скрипт ставит Python, nginx и сертификат Let's Encrypt, запускает CRM и ежедневные
резервные копии как службы. Без своего домена используется адрес `<ip-через-дефисы>.sslip.io`.
Свой домен: `... | bash -s crm.ваш-домен.ru`. Повторный запуск того же скрипта обновляет код.
