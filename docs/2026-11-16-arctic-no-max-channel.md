# У Арктики нет чата/канала MAX — уточнение 16.11.2026

Юлия подтвердила отсутствие чата Арктики в MAX. Это намеренное отсутствие канала, а не недостающая ссылка. Напоминание на 17:05 МСК отключено; сервис подтвердил `is_enabled=false`.

Для Арктики пустое поле канала MAX теперь не блокирует ручной скрипт правил: из стандартного текста исключается приглашение подписаться и абзац о новостях в канале. Сохраняются актуальный PNG, оферта Арктики и отдельная ссылка «Написать нам в MAX». Telegram-ссылка не подставляется. У Неба/Западного ссылки по-прежнему обязательны, у малышей — каналы Неба. В настройках Арктики явно пояснено, что MAX можно оставить пустым. Локальный JSON импорта вне репозитория дополнен пустым полем MAX Арктики.

Пройдены 11 тестов chat_scripts, включая готовый черновик Арктики без MAX-канала, наличие картинки/оферты/контакта, отсутствие призыва/Telegram, отсутствие отправки при выборе и сохранение запрета при пропущенной обязательной ссылке другого филиала. JavaScript syntax и git diff --check. Изменение не отправляет сообщения клиентам и не переписывает рабочие настройки; публикация проверяется отдельно. Сетевой блокер доставки Telegram не снимается.
