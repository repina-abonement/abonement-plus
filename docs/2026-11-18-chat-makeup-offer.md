## Поведение

Каналы Telegram → MAX → WhatsApp доступны сразу кнопками со значками. Нативный select остаётся скрытым источником значения для прежних обработчиков. Смена канала не вызывает отправку и сохраняет введённый текст. При нескольких адресатах одной сети показаны различающие подписи. Выбранный родитель виден в том числе на мобильном

В карточке и inbox добавлена кнопка «Предложить отработку». При доступных пропусках — акцент/число; при нуле — нейтральная. Остаток загружается лёгким GET summary без сканирования групп. При нескольких детях есть выбор, первым предлагается ребёнок с остатком. Клик готовит редактируемый текст и сразу вставляет в пустое поле ответа. Непустой пользовательский черновик сохраняется; для его замены нужно отдельное действие и подтверждение. Ни запись, ни отправка автоматически не выполняются

## Правила и подбор

Существующие makeuppolicy, program, capacity и clientattendance остаются источником правил. Месяц пропуска или следующий; оплаченный абонемент на месяц отработки; минимум две обычные оплаченные тренировки в неделе, без требования дождаться их посещения. Только отмеченные доступные/неиспользованные пропуски, активные группы/филиалы, действующее расписание, без закрытий, с учётом возраста и записей ребёнка. Вместимость считается общим capacity (абонементы, ПУ, отработки/разовые/резервы), не одной численностью состава

Чатовый режим сортирует сначала по дате/времени, затем загрузке; существующая сортировка панели посещений по меньшей загрузке сохранена по умолчанию. Горизонт 21 день, до 5 безопасных вариантов. Предложения с возрастным предупреждением/необходимостью согласования не попадают в текст. Это не отменяет согласование для ручного бронирования. Если дата рождения неизвестна, нужно уточнить её; произвольная возрастная группа не предлагается
