# Ручная скидка и единый итог — 17 ноября 2026

## Источник и причины

Обычный quote_for собирал [ручная скидка, автоматические] и выбирал максимальный процент. Поэтому ручные 10% проигрывали автоматическим 20%, вопреки новому правилу. auto_discounts выбирал записи по rule=first_on_trial_day/sibling без запрета названия «Многодетная семья»: неверно классифицированная/переименованная запись могла попасть в авто. В стандартной начальной конфигурации многодетная имеет rule=manual; реальный rule записи рабочей CRM не прочитан, утверждать конкретное изменение настройки нельзя. Публичный API карточки отдавал только rule=manual, скрывая другие варианты из обычной продажи

## Реализация

money.choose_discount — один выбор: явный действующий discount_id заменяет автоматический; none отключает; без выбора используется прежний максимум процента. Многодетная (имя/специальное правило) запрещена в авто даже при неверной классификации. Для ручной многодетной проверяется роль пользователя сервера: admin (руководитель) или operator (администратор, включая офлайн). Без пользователя, тренер/стажёр/юрист получают 403. Списки/несколько ID не принимаются

Обычная продажа, сборная и прошедшая покупка используют единый выбор; актор передаётся от HTTP-сессии до расчёта и сохранения. В сборной автоматически по-прежнему только семейная скидка, но явный действующий ручной выбор заменяет её по новому указанию. Правила срока оплаты не меняются, скидки после срока не добавляются. Везде максимум одна скидка. Для поля auto учитывается именно способ выбора, а не технический rule записи

student_detail отдаёт все действующие скидки без отсечения автоматических. Прошедшая покупка уже отдавала весь список. Архивные не предлагаются. Добавлена подсказка ручного выбора. Семейные флаги/число детей не применяют многодетную автоматически

Нет миграции суммы/скидки старых subscriptions/payments/pay_links, нет массового пересчёта. quote_for остаётся расчётом новых продаж; старые строки и неизменность их сумм проверены. Штатные прежние правила времени оплаты не отключались
