# Документы при первом входе стажёра

Исправлен пропуск экрана документов для роли trainee. До работы в Планере стажёр принимает все пять существующих документов: NDA, правила работы с персональными данными клиентов, согласие на обработку своих данных, уведомление о журнале действий, соглашение о простой электронной подписи.

Возвращён реальный счётчик непринятых документов в метаданных, разрешены чтение документов и отправка принятия для собственного аккаунта. При наличии непринятых документов сервер закрывает маршруты Планера и выполнение задач. Обзор подписей команды и документы других пользователей стажёру недоступны. После обновления текста требуется принятие новой редакции. Само принятие выполняет сотрудник; автоматически согласия не проставляются.

Проверки: HTTP tests.test_trainee — пять документов, отказ в доступе к Планеру до принятия, отказ при неполном списке, успешное принятие, отсутствие повторных записей при повторной отправке, сохранение IP/времени/хеша, повторная блокировка после изменения редакции. tests.test_staffdocs прошёл. Chromium: пять чекбоксов и поле имени, отсутствие Планера до принятия и открытие после; ошибок JavaScript нет. В общем наборе сохраняются те же четыре ранее подтверждённые ошибки test_coachreport, test_planner, test_pu, test_required.
