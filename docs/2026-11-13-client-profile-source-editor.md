# Редактируемая шапка, основной родитель и редактор рекламных источников

## Требования Юлии

В шапке клиента редактируются отображаемые данные; можно добавить второго родителя и указать приоритетного для общения. Действия находятся справа сверху: корзинка (внутри существующий выбор месяц/разовое), ПУ в применимом потоке записи, телефон; второстепенные действия — в меню. Рекламные каналы и источники редактируются в настройках непосредственно на месте. Раскрывающиеся секции/плашки рекламного справочника заменить ясным редактором.

## Клиент и контакты

Добавлена встроенная форма шапки: имя, дата рождения, статус, заметка; для лида дата/время ПУ. У каждого родителя имя, родство, телефон, необязательная почта, мессенджер/username, одна общая радиогруппа основного контакта. Добавление не удаляет прежние контакты. Группа открывает существующий безопасный процесс перевода по действующему абонементу либо выбор группы ПУ; оплаченный состав не меняется простым PATCH.

PATCH profile требует members:full. Изменения атомарны, сверяется ожидаемая версия ребёнка/заметки/всех семейных контактов, отклоняются чужие ID и повторные телефоны/другая семья. Записи контактов не удаляются. Смена статуса/ПУ проходит существующие сервисные проверки и правила этапов; редактирование имени/контактов само по себе не меняет статус или задачи. Сохранение пишется в историю и аудит.

is_primary сохраняется в parents. Карточка и проверка обязательных данных берут его первым; звонок предлагает его номер. Выбор диалога по умолчанию ищет основной контакт по точному нормализованному телефону или username; выбор администратора внутри текущего основного контакта сохраняется. При смене основного прежнее предпочтение выбора диалога сбрасывается новым ключом. Общая история всех родителей сохраняется. Автоматический best_conversation не подменяет отсутствующий диалог основного чужим родителем; прежний fallback семьи работает, когда основной явно не задан. Сообщения при редактировании не отправляются.

## Каналы и источники

Вместо аккордеонов — список каналов и редактор источников выбранного канала. Названия редактируются текстом; есть добавление, перенос источника в другой канал через явный список, убрать/вернуть и просмотр архива. Сохранён импорт текстового списка ERP. Новый источник/перенос в архивный канал запрещён. Повторы имён проверяются без учёта регистра; интерфейс передаёт исходное состояние для защиты от устаревшего редактирования.

Удаление из выбора означает архивирование: ID источников в карточках/отчётах не меняются, источники архивного канала не попадают в активный выбор. Перезапуск больше не восстанавливает старое имя стандартного канала после переименования: первоначальное заполнение одноразовое. Уже выбранный архивный источник не теряет свой ID в селекторе клиента. Права редактора остаются admin, операторский просмотр справочника сохранён.
