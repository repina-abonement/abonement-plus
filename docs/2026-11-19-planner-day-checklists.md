# CRM-161 — режим дня и подзадачи

Юлия запросила открывать текущий день вместо всей недели и списки подзадач с галочками внутри задачи. Во время разработки уточнила терминологию: «Утренняя» и «Основная», а не «Вечерняя».

## Результат в коде

- В планере переключатель День / Неделя. День открывает сегодня, стрелки листают по одному дню, кнопка Сегодня возвращает текущую дату. Серверный week API с days=1 возвращает один день, по умолчанию прежние семь. Фильтры статуса/смены и выбор доски сохраняются. Просроченные задачи остаются отдельным блоком.
- Список при создании задачи: каждый пункт с новой строки. В открытой задаче можно отметить, снять отметку, добавить/удалить пункт. Видны счётчик, автор и время отметки. Завершение родительской задачи остаётся отдельным действием.
- В карточках доски виден прогресс подзадач. Списки хранятся сервером, а не только в браузере.
- Для повторов хранится шаблон; каждый новый день/смена получает отдельные строки без галочек. Идемпотентная генерация не стирает имеющиеся отметки. При изменении списка одинаковые пункты текущей задачи сохраняют ID, автора и галочки; новые пункты не отмечены. Для будущего шаблона используется существующая область «Эта и будущие задачи».
- Ограничение 50 подзадач по 200 символов, проверка доступной открытой задачи и принадлежности item_id к task_id. У наблюдателей нет изменений, у Вари и членов общего пула доступ соответствует правам планера.
- Смена подписана «Основная» в заголовке, фильтре, формах и списке повторов. Внутреннее значение evening не меняется, чтобы не переписывать старые задачи/ключи и не потерять отметки.

## Проверки

11 профильных серверных/HTTP тестов: один/семь дней, независимые списки смен/дат, повторное открытие/генерация, сохранение галочек при правке, будущий шаблон, миграция, права, чужой пункт, завершённая задача, лимиты. Настоящий локальный HTTP-сервер: получение одного дня, добавление, отметка, чтение после изменения и удаление подзадачи.

Шесть прежних сценариев планера/общей доски пройдены. Chromium исполнил настоящий JS с синтетическим API: День/Неделя, сегодня/соседние дни, добавление/отметка/удаление, автор/время, блокировка наблюдателя; отдельно повторена проверка цветных смен, фильтра и формы обеих смен.

Рабочая авторизованная проверка после обновления не выполнена. Пользователь ранее сообщила «заработало» о загрузке планера после временного экрана ошибки; причина того сбоя журналом не установлена, это не доказательство всей новой функциональности.
