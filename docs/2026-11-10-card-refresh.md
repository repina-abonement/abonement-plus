# Восстановление карточки после обновления

В истории вкладки сохраняются ID клиента, вкладка карточки и ID вошедшего сотрудника. После обновления страницы CRM заново проверяет текущую сессию и права, загружает карточку и открывает ту же вкладку. Дополнительный переход в историю при восстановлении не создаётся. Закрытие крестиком/Escape убирает сохранённую карточку; Back/Forward восстанавливают ожидаемый экран. Другие модальные формы не выдают себя за карточку клиента.

Не сохраняются имена/телефоны в URL и черновики финансовых операций. Для другого аккаунта, стажёра или сотрудника с обязательными непринятыми документами карточка не восстанавливается. При удалении/недоступности карточки сохранённое состояние сбрасывается.

Проверка Playwright на 390/1440: обновление на вкладке абонементов, история без дополнительных записей, Back/Forward, закрытие и повторное обновление, смена аккаунта на стажёра. Все сценарии прошли, ошибок JS нет.
