# Отмена автоматического напоминания через пять минут — 16.11.2026

Юлия прямо отменила опубликованную правку «Через 5 минут без ответа чат становится красным и поднимается наверх». Это позднее решение заменяет прежнее требование CRM-078.

Удалены вычисление очереди ожидания ответа, автоматическое непрочитанное, срочная красная подсветка/подпись и приоритет над закреплёнными. Порядок снова обычный: сначала личные закрепления, далее дата переписки. Непрочитанное определяется настоящими входящими и ручной отметкой. Для уже открытых старых вкладок совместимые API-поля срочности возвращают false/0, чтобы прежний JS не показывал срочность.

Прежняя автоматика была вычисляемой и не записывала искусственные unread в БД, поэтому массовое обнуление не требуется и не выполняется. Настоящие непрочитанные и ручные отметки не стираются. Контекстное меню, звук/архив/закрепления, счётчик «Новые», названия из карточек, полный мобильный экран и черновики сохраняются.

Проверки: chat_actions (8), offline_chat_access, test_comms и history_group_pins; синтаксис JS, compileall, git diff --check. Локальный HTTP+Chromium с синтетическими чатами старше пяти минут: закреплённый остаётся первым, красной срочности нет, после чтения/фонового обновления чат остаётся прочитанным; ручная отметка и контекст работают. Реальные сообщения/данные не менялись. Публикация фиксируется отдельно.
