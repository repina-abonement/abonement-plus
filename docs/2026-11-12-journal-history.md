# Исторические отметки в журнале

Дневной журнал дополнен фактическими attendance по точным group_id и date независимо от текущего состава, архива, выбытия, перевода и выбранных дней ученика. Каждая фактическая отметка показывается один раз; статус, заметка, признак предупреждения и обработки пропуска сохраняются. Отпуск не перекрывает фактический статус. В ответе фактической отметки присутствуют attendance_id, group_id и date для точной сверки.

Месячный журнал включает фактические даты attendance, отсутствующие в текущем расписании. Для отработок сохранены метаданные записи и корректное отображение статуса, без двойного счёта.

В test_journal_month добавлен сценарий 35 + 8 исторических отметок. Сверяется множество (student_id, date, status), точная принадлежность группе, отсутствие дублей и записей другой группы/месяца. Дополнительно проверены архив, выбытие, перевод, индивидуальные дни, отпуск, дата вне расписания и отработки. Проверка чтения не изменяет базу.

Проходят test_journal_month, test_transfer, test_schedule, test_subscription_dates, test_client_attendance, test_program_transfer. test_singles останавливается на проверке фиксированной даты напоминания до обращения к журналу; этот сценарий не относится к изменению журнала.

После отдельного разрешения пользователя рабочая группа «Небо, вт/пт 16:45, 3–4» (ID 11) за октябрь 2026 проверена через TinyFish. В дневных журналах получены 43 уникальные отметки: 32 present и 11 absent, без повторов по ID и сочетанию ребёнок/группа/дата. Месячный ответ подтверждает 35 обычных и 8 исторических записей. Все восемь сопоставлены с календарями карточек по attendance_id, student_id, group_id, дате и статусу, расхождений нет. У всех group_id=11; перепривязка не потребовалась. Привязки записей, платежи не изменялись; повторный импорт и отправка сообщений не выполнялись. Число 43 совпадает с ориентиром ERP, данным пользователем; исходная ERP-выгрузка в этой проверке заново не читалась.

Для проверяемой построчной сверки месячный ответ дополнен списком attendance: ID отметки, ID ребёнка, ID группы, дата, исходный статус и признак записи, не прошедшей прежний отбор состава. Это только чтение уже существующих данных. Регрессионный тест проверяет все 43 записи и ровно 8 исторических. Пользователь отдельно разрешил чтение этой рабочей группы через TinyFish; проверка выполняется без изменений данных.
