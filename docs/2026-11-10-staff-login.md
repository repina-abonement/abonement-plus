# Автоматические данные входа и изменение логина

В форме добавления сотрудника остаются имя и фамилия, необязательный телефон, должность и отметка промоутера. CRM формирует уникальный логин транслитерацией имени с числовым суффиксом при совпадении и случайный пароль из 18 символов. После создания руководителю показывается отдельная карточка с данными входа и кнопкой копирования. Пароль отображается один раз, в базе хранится только хеш. Пустое имя не принимается. Ответ с данными входа доступен только руководителю и не кешируется.

Рядом с логином существующего сотрудника добавлена кнопка редактирования. Менять может только руководитель. Проверяются допустимые символы, длина и уникальность без учёта регистра (включая архив). Пароль, идентификатор сотрудника и связанные задачи сохраняются. Изменение фиксируется в журнале действий.

Проверки: tests.test_login_edit проверяет права, смену логина, вход с прежним паролем по новому логину, конфликты и ошибки, автоматические уникальные логины, разные случайные пароли, создание стажёра только с Планером, сохранение телефона и отсутствие пароля в списке сотрудников. Chromium: автосоздание, копирование данных входа и правка логина. Ошибок JavaScript нет. Общий набор имеет те же четыре ранее подтверждённые ошибки test_coachreport, test_planner, test_pu, test_required; новые проверки прошли.
