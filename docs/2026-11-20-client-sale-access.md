# CRM-176 — корзинка продажи в карточке для администраторов

Юлия сообщила, что Варя и офлайн-администраторы не видят верхнюю корзинку продажи абонемента. Позднейшим уточнением установила порядок: сначала опубликовать кнопку, затем вернуться к ошибке чтения карточки CRM-177. Рабочие финансовые данные в этой задаче не изменяются.

В интерфейсе `act-sell` зависела от общего `members:full`. У офлайн-роли такого права нет; сервер также запрещал quote/invoice/paylinks и удалял группы из метаданных. Поэтому одного показа значка недостаточно. Обычный operator/senior по прежней модели уже имел полный доступ; конкретные рабочие флаги и сессия Вари из этого окружения не прочитаны.

Добавляется отдельное право `client_sales`: оформление покупки из карточки для руководителя, администраторов и офлайн-администраторов. Оно используется для корзинки и необходимых запросов формы: расчёт, оформление, ссылка, проверка ссылки, подтверждение выбранного зачёта. Форма получает активные группы и только необходимые настройки цен. Право не создаёт новый раздел меню, не предоставляет офлайн-роли общий `members:full`, административные операции с деньгами, импорт, выгрузку или настройки интеграций.

Для отсутствующих обязательных сведений разрешено заполнение только полей стандартного шага перед продажей. Обычное редактирование всей карточки не расширяется. Поведение расчёта месячного счёта и выключенный по умолчанию зачёт баланса сохраняются.

56 проверок Chromium прошли на настоящих `meta`/`student_get` ответах временной БД: карточка → корзинка → группы/месячный расчёт → форма полученной оплаты; существующий счёт → локальная ссылка → свежая проверка → копирование. Проверены модель обычного администратора и офлайн-роль, отсутствие нового пункта меню и общего редактирования, совместимость прежнего `members:full`. Рабочих счетов/оплат/отправок тесты не создают.

42 серверных проверки прошли, включая пять новых HTTP-проверок, прежний доступ к чатам и месячные расчёты. Отдельный прежний сценарий `test_perms` также прошёл. Необходимые действия доступны, посторонние финансовые/административные действия остаются запрещены. Опубликованная версия дополняется после проверки. Авторизованное нажатие в рабочих сессиях Вари и офлайн-администраторов отдельно не выполнено. Диагностика CRM-177 готовится отдельным шагом; её файлы первым релизом не публикуются.
