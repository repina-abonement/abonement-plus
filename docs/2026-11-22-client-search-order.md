# Поиск клиентов независимо от порядка ФИО — 22.11.2026

## Воспроизведение

На обезличенной карточке:

- «Минибаев» — найден;
- «Дамир» — найден;
- «Минибаев Дамир» — найден;
- «Дамир Минибаев» — не найден;
- «Анна Минибаева» — найдена как родитель;
- «Минибаева Анна» — не найдена;
- телефон без форматирования — найден.

Обычные и офлайн-администраторы имеют серверное право `search`; отказ роли не воспроизведён. Ошибка была общей для быстрой строки и полного списка клиентов.

## Исправление

Имя больше не сравнивается с полным запросом как с одной подстрокой. Для каждого варианта раскладки запрос разбивается на слова. Все слова должны найтись, но могут идти в любом порядке и находиться в имени ребёнка, семьи или одного из родителей. Телефон продолжает обрабатываться специализированным сравнением. Оба API используют одну функцию построения условия.

В быстрой строке прежнее проглатывание ошибки API заменено понятным сообщением «Поиск временно недоступен. Повторите ещё раз».
