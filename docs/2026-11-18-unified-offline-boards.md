# Одна доска офлайн-администраторов — 18 ноября 2026

CRM-054, новое прямое поручение Юлии: Виктория Сафронова и Татьяна Данейкина — офлайн-администраторы, вместо трёх вариантов нужна одна общая доска с доступом им, Варе и руководителю

## Реализация

- Однократная startup-миграция offline_planner_unified_v2 с полным однозначным совпадением имён Виктории/Татьяны. Варя определяется однозначно, с предпочтением полного имени. При неоднозначности изменений/скрытия досок нет
- Переносятся все планерные задачи двух досок независимо от автора/статуса, а также активные/неактивные повторы. Клиентские и чужие задачи не затрагиваются
- Меняется только назначение на существующий общий pool, без копирования/удаления задач. ID, описания, даты, результаты, авторы/отметившие выполнение сохраняются. Аудит содержит прежние назначения задач/повторов
- Маркер записывается последним внутри SAVEPOINT; повторный запуск не меняет задачи повторно
- Две личные доски не предлагаются в выборе недели, создании/изменении задач, командном обзоре. Старые user/assignee_id переводятся на общий pool сервером
- Сотрудницы сохраняются как люди/аккаунты: доступны руководителю для дней рождения и настройки наблюдателя, без двух дополнительных досок
- Офлайн-сотрудницы и руководитель редактируют, Варя остаётся наблюдателем только на просмотр по ранее утверждённому правилу. Посторонние, включая прочих старших, не получают доступ
