# Стикеры из файлов и необязательная почта перед продажей

## Требования Юлии

17 ноября: разрешить продолжить предпродажную форму без почты. После подтверждённой ошибки импорта Ольги через недоступные мост/Telegram Юлия поручила добавить загрузку файлов напрямую в CRM

## Реализация

- Стикеры → название набора → «Загрузить картинки», несколько PNG/WEBP/JPG/GIF; только администратор, каталог общий для команды
- Браузер преобразует картинку в PNG до 512×512 с прозрачностью; анимация становится статичной. Не более 120 файлов за выбор/набор, 10 МБ на исходник, 1 МБ на преобразованную картинку
- Сервер проверяет base64, PNG, размер/CRC/окончание файла, исключает дубли по хешу в наборе. При частичной ошибке интерфейс показывает добавленные/уже существующие/ошибочные файлы
- Нет Telegram Bot API, моста или сторонней службы при загрузке. Wazzup получает штатный contentUri на PNG; подтверждение messageId обязательно. Нативный Telegram отправляет загруженные изображения через sendPhoto, не пытается использовать локальный хеш как Telegram file_id
- При продаже email остаётся в missing для отдельного запроса данных, но исключён из блокирующих полей. Пустой email разрешён, непустой проверяется, сохранённый адрес пустым не стирается. Прочие обязательные поля прежние
- Настройки PayKeeper и обязательность почты в его платёжной форме не менялись; проверка CRM-022 остаётся отдельной задачей

## Проверки

Новые тесты: офлайн-загрузка/каталог/дедупликация/повреждённый файл, Wazzup payload, продажа без почты, сохранение имеющегося адреса. test_required проходит с фиксированными часами для старого сценария ПУ; проверяет отсутствие почты, ошибочный адрес и последующее добавление

Chromium с локальным HTTP и синтетическим Wazzup: выбор файла, появление в каталоге, ручная отправка, получение PNG по публичной ссылке, HTTP 200 от mock-провайдера; предпродажная форма сохраняется с пустой почтой; ошибок JavaScript нет. Это не отправка настоящему клиенту

Полный набор Ольги не импортирован автоматически и реальному контакту стикер не отправлен. Для нового способа нужны сохранённые файлы набора; исходная проблема Telegram-сети отдельно не исправлена. Публикация фиксируется отдельно
