# Клиентские задачи и привязка переписки

Клиентские задачи общие для всех администраторов: время и выбор исполнителя убраны из формы правки и создания. Срок задаётся датой, на сервере хранится конец дня. Введён признак приоритета: важные задачи первыми внутри колонки на тот же день; задача на будущую дату не появляется раньше. Сортировка применяется также в карточке клиента. Личные задачи Планера сохраняют свой порядок доступа и исполнителя.

Доска показывает короткие карточки: название, клиента, дату и действия. Контакты и подробное описание вынесены во всплывающее окно при наведении/фокусе. На телефоне есть кнопка «Подробности». Окно не обрезается горизонтальными колонками, закрывается по Escape и при уходе со страницы. Сверху доски добавлены кнопки прокрутки и диапазон видимых колонок.

Проверены серверные сценарии общих клиентских задач, приоритета внутри дня, доступа другого администратора, закрытости личных задач, формы без времени/исполнителя. Пройдены test_tasks, test_erpboard, test_client_tasks_shared, test_trainee, test_planner_edit. В браузере проверены desktop/mobile: компактность, наведение/фокус/нажатие, всплывающее окно, очистка при навигации, приоритет в форме и доступ к крайней правой колонке.

Рабочая CRM: после указания точного Telegram-логина пользователем диалог семьи Миллера привязан к карточке. Повторное чтение данных семьи подтвердило ту же Telegram-переписку и 23 сообщения. Исходящих сообщений не отправляли. Первоначальный результат с сокращённым логином оказался неточным; действие выполнено после точной сверки.
