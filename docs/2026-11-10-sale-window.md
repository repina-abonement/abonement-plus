# Окно продажи абонемента

- Удалена отдельная кнопка «Только выставить счёт». Счёт по-прежнему создаётся для ссылки на оплату и при регистрации оплаты.
- Для продления предлагается группа из последнего неотменённого абонемента, если запись в группу активна; без истории — основная группа клиента, затем первая доступная.
- Тариф предлагается из предыдущего абонемента выбранной группы. Группу и обычный тариф можно изменить в окне продажи.
- Выбор обычного тарифа больше не отправляет PATCH записи клиента: расчёт и новый счёт получают выбранный тариф отдельно. Старые абонементы не меняются.
- Во время перерасчёта оплата недоступна; устаревшие ответы расчёта игнорируются.
- Текст ссылки на оплату без приветствия: месяц, ребёнок; группа и тариф; сумма; ссылка. Блоки разделены пустыми строками.
- По уточнению Юлии: в Арктике после 25-го скидки не действуют. Существующее правило сохранено.

Проверка: браузерный сценарий с вымышленными данными проверил выбор предыдущей группы/тарифа, ручную смену, отсутствие PATCH и удалённой кнопки, формат сообщения. test_pricing и test_sbornaya прошли. Общий прогон: прежние ошибки test_planner, test_pu, test_required; новых ошибок нет.
