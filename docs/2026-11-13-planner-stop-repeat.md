# Остановка повторяющихся задач по просьбе Вари

Проблема: настройки выполненного экземпляра скрывались целиком, поэтому из его карточки нельзя было остановить серию. Существовавшая кнопка во вкладке «Повторы» не решала этот сценарий.

Управление серией вынесено отдельно от редактирования задачи. Кнопка «Убрать будущие повторы» есть в карточке выполненного/открытого экземпляра и во вкладке «Повторы». Перед действием подтверждается: серия отключается, открытые экземпляры на сегодня и будущие даты отменяются, прошлые просроченные и все выполненные остаются. Отмена записывает время и исполнителя; физического удаления задач нет. Повторный запрос безопасен, другие серии и разовые задачи не затрагиваются. Существующие ограничения доступа сохранены.

Локально прошли test_planner_stop, test_planner_edit, test_trainee, Python/JS syntax. Chromium 390/1440 проверил кнопку выполненной задачи, отказ от подтверждения, ошибку API с повторной попыткой, endpoint и обновление интерфейса. Это не изменение реальных задач Вари. Публичные файлы проверяются после push отдельно; авторизованный рабочий сценарий недоступен из-за отрицательного баланса TinyFish.
