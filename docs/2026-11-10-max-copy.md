# Копирование описаний задач и проверка маршрутизации MAX

## Описание задачи

Рядом с заголовком описания добавлена кнопка «Скопировать описание». Сохраняются исходные переносы строк и символы. После успешного копирования появляется «Описание скопировано». Если Clipboard API недоступен, используется резервное выделение; если и оно не срабатывает, открывается поле для ручного копирования. Текст описания разрешено выделять вручную, включая сотрудников без права выгрузки всей базы. Запрет копирования других экранов не снимался.

## MAX через Wazzup

Проверены текущая реализация и актуальная русскоязычная документация Wazzup: https://wazzup24.ru/help/api-ru/otpravka-soobshhenij/ — chatType=max, для начала диалога допускается phone без плюса. Англоязычная страница отстаёт и не содержит этих сведений.

В карточку семьи добавлен новый диалог MAX по телефону. При нескольких доступных мессенджерах отправка из карточки требует явного выбора; выбор хранится в состоянии интерфейса отдельно для пользователя и семьи, сохраняется после обновления ленты. В открытом диалоге MAX выбран его собственный канал, рядом с редактором видна подпись «Отправка: MAX»; при осознанном переключении подпись меняется.

Устранена подстановка канала и chatType WhatsApp при отсутствии метаданных MAX/Telegram. Маршрут определяется типом переписки, сохранённым channelId или настройкой именно этого мессенджера. Если настройка отсутствует либо известный транспорт не совпадает, отправка прекращается с ошибкой. Защита применяется и к тексту, и к графическим стикерам. Неизвестное значение channel в семейном маршруте отклоняется вместо выбора WhatsApp.

Входящие события maxapi нормализуются в MAX. Чат, начатый по телефону, получает реальный chatId по точному совпадению номера или идентификатора отправленного сообщения. Угадывания по «единственному недавнему диалогу» для MAX нет. В настройках Wazzup отдельно показаны признаки подключения WhatsApp, Telegram и MAX.

## Проверки и ограничения

Сохранён прежний tests.test_wazzup_max: входящие MAX/WhatsApp, ответ в тот же канал и общая история семьи. Новый tests.test_wazzup_max_routing проверяет старт MAX по номеру, вебхуки, привязку семьи, текст и стикеры, отсутствие подстановки WhatsApp при пропавших/ошибочных метаданных, семейный маршрут и отклонение неизвестного канала. Сервисы подменены, реальные сообщения никому не отправлялись.

Chromium в мобильном размере: копирование описания, сохранение строк/символов, ручное выделение при no-copy, резервный способ; наличие MAX в выборе семьи, запрет отправки без выбора, сохранение выбора после обновления, исходный MAX при открытии его диалога и видимая подпись канала. Ошибок JavaScript нет.

Авторизация и состояние реального канала Wazzup/MAX на рабочем аккаунте ещё не подтверждены: нужен сохранённый вход руководителя в CRM. Контрольная доставка в настоящий MAX в рамках этих проверок не выполнялась.
