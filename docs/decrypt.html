Расшифровать копию CRM

Работает прямо в браузере, без интернета: файл и пароль никуда не отправляются.

  1. Копия базы (crm-….sqlite3.gz.enc) сохранится как файл .sqlite3. Его открывает бесплатная программа DB Browser for SQLite (sqlitebrowser.org), или программист возвращает его в CRM.
  2. Фото (…jpg.enc) сохранятся обычными картинками.
  3. Для просмотра клиентов проще открыть Excel из папки Excel на Яндекс Диске: он не зашифрован и обновляется каждый час.
