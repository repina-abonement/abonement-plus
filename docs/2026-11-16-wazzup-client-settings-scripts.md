# Связь с клиентами, Wazzup и согласованные скрипты — 16.11.2026

## Требования и результат в коде

- На скрине пользователя WhatsApp, Telegram и MAX Wazzup активны и выбраны в CRM. Это подтверждает настройку, не реальную доставку. Для Telegram через Wazzup отдельный Bot API/мост не нужен. Telegram-бот убран из выбора клиентского ответа, история сохранена. Служебные боты и их настройки не удаляются.
- В карточке последняя действующая переписка семьи выбирается автоматически, в том числе когда у импортированного диалога не заполнен телефон. Сохранённый ручной выбор сохраняется. Приоритет существующего диалога выше открытия нового; показаны канал/адресат и кнопка «Изменить», повторного вопроса о мессенджере нет. В открытом диалоге ответ остаётся в нём; переход из истории бота в Wazzup допускается по однозначно совпавшему получателю той же семьи. Для автоматических сообщений такой переход требует однозначного телефона/Telegram peer; неоднозначность не разрешается догадкой.
- Wazzup v3 запрещает `text` вместе с `contentUri`: исправлена отправка файла, затем отдельного текста тому же получателю. История сохраняет оба подтверждения. При частичной ошибке файл не повторяется, текст остаётся в черновике; повтор текста требует проверки доставки. Успешный повтор всего запроса идемпотентен. Источник протокола: https://wazzup24.ru/help/api-ru/otpravka-soobshhenij/.
- Настройки связи: три основных раздела «Мессенджеры», «Телефония», «Заявки с сайта». Статусы и проверка каналов видны сразу; ключи, адреса, служебные боты/логи скрыты под настройкой. Ключи отображаются password-полями. Редактор открывается один за раз.
- GET настроек больше не пишет `public_url` в SQLite. Воспроизведён конфликт старого GET с параллельной записью; новый GET проходит при занятом writer. Без production-логов нельзя объявлять это точной причиной скрина 500. Ошибка загрузки теперь показывает сообщение и повтор вместо вечного «Загружаю». Сохранение Wazzup не сбрасывает статус неизменённого бота.
- В верхнем меню карточки добавлен «Перенести в архив»/«Вернуть из архива» с прежним подтверждением и правами. Архивируется один ребёнок; семья/другие дети/оплаты не удаляются. Рабочая тестовая карточка не архивировалась.
- Согласованы: Западный — запись на ПУ и за два часа; Небо — за день; общий текст после ПУ с подписью «Оля💚». Дата/время — из реальной записи, приветствие — по времени Москвы. Западному подставляется свой канал, а не ошибочно вставленная в примере ссылка Неба. В MAX используются MAX-ссылки. Шаблоны редактируются в настройках скриптов. Текст после ПУ заменяется однократно с сохранением предыдущего; дальнейшие ручные изменения сохраняются. `auto_live` этим релизом не включается, расписание автосообщений не меняется.
- По уточнению пользователя треугольники убраны у раскрывающихся блоков во всём интерфейсе: «+» закрыто, «−» открыто, клавиатурное управление сохранено. У select убрана нативная стрелка, меню обозначено многоточием. Выбор мессенджера обычно скрыт за «Изменить».
