## Готово в коде, проверено локально

- Полноценный выбор группы/тарифа/ОФП при продаже, календарь и перерасчёт только по запросу.
- Одна кнопка продажи в шапке; читаемый текст оплаты с «Сборная Арктика».
- Большое поле сообщения, компактные контакты, возраст с месяцами.
- Допуск сборной по решению тренера вместо возрастного порога.
- Поиск клиента отделён от полей учётных данных.
- Автопривязка существующих Telegram-диалогов по однозначным идентификаторам.

3. MAX: проверено в рабочих настройках — Wazzup MAX подключён, active, видимых ошибок нет. Отдельный MAX-бот не подключён. Доставка не проверялась, сообщения клиентам не отправлялись.

- Четвёртая вкладка «Посещения»: календарь с типами занятий, итогами и доступными отработками. Запись/отмена, предложения по минимальному числу детей, редактируемое сообщение без отправки.

- Карточка/вкладка/месяц сохраняются после обновления; восстановление ограничено текущим пользователем.
- Локальные проверки desktop/mobile пройдены. Три прежних сбоя общего набора: test_planner, test_pu, test_required; новые целевые тесты проходят.
