# Очередь работы CRM

После каждого завершённого блока: проверить результат, отделить состояние кода от состояния рабочего сайта, перейти к следующему доступному пункту. В сообщении Юлии называть следующий шаг и конкретный блокер, если он есть. Готовые запросы не оставлять ждать повторного поручения.

## Готово в коде, проверено локально

- Полноценный выбор группы/тарифа/ОФП при продаже, календарь и перерасчёт только по запросу.
- Одна кнопка продажи в шапке; читаемый текст оплаты с «Сборная Арктика».
- Большое поле сообщения, компактные контакты, возраст с месяцами.
- Допуск сборной по решению тренера вместо возрастного порога.
- Поиск клиента отделён от полей учётных данных.
- Автопривязка существующих Telegram-диалогов по однозначным идентификаторам.

## Следующие пункты, требующие проверки на рабочем подключении

2. Переписка семьи Миллера: 11 ноября привязана в рабочей CRM после подтверждения точного логина. Проверка данных семьи подтвердила Telegram-диалог и 23 сообщения; сообщений не отправляли.
3. MAX: проверено в рабочих настройках — Wazzup MAX подключён, active, видимых ошибок нет. Отдельный MAX-бот не подключён. Доставка не проверялась, сообщения клиентам не отправлялись.

5. Сквозная доставка собственных стикеров через Wazzup/MAX: проверить формат WEBP/статичные превью на согласованном тестовом адресате, когда будет дан адресат. Реальные клиентские сообщения не отправлять без явного поручения.

Юридическое оформление электронной подписи: по запросу подготовлен промпт для отдельной проработки. Юридическая проверка и изменение юридических текстов пока не заказывались.

## Блок календаря и финансов — 10 ноября

- Четвёртая вкладка «Посещения»: календарь с типами занятий, итогами и доступными отработками. Запись/отмена, предложения по минимальному числу детей, редактируемое сообщение без отправки.
- Читаемые карточки абонементов и история платежей. Единая продажа на месяц/разовое; повторное использование счёта, частичная оплата.
- Убран отдельный блок групп. Перевод рядом с абонементом. Для сборной Юлия утвердила общий зачёт оставшихся Арктики и ОФП: новая группа оплачивается общей суммой, разница — доплата или баланс. Реализовано и проверено.
- Карточка/вкладка/месяц сохраняются после обновления; восстановление ограничено текущим пользователем.
- Локальные проверки desktop/mobile пройдены. Три прежних сбоя общего набора: test_planner, test_pu, test_required; новые целевые тесты проходят.

- Рабочий сайт: календарь и единая продажа подтверждены после публикации 5566987.
- Перевод из сборной: общий зачёт Арктики и ОФП, выбор обычного тарифа, предварительный расчёт по реальным платежам. История до перевода сохраняется. Неоднозначные старые абонементы с несовпадающим количеством дат требуют уточнения; суммы не угадываем.
