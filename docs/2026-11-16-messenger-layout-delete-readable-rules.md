# Новый вид чатов, удаление сообщений и понятные отработки — 16.11.2026

## Подтверждённые требования

Юлия попросила кнопку удаления отправленного сообщения, понятные пункты отработок в картинке, заметную маркировку непрочитанного слева и визуальную структуру чатов как в Telegram. Отдельное предпочтение для клиентских текстов/памяток: не ставить точки в конце абзацев. Ранее согласованные ограничения отработок остаются прежними.

## Что изменено

- На компьютере список диалогов и текущая переписка расположены рядом, без отдельного модального окна. На телефоне список/диалог открываются по очереди, есть возврат. Поиск и фильтры компактные, у строк аватары с инициалами, имя, время, одна строка предпросмотра. Красный счётчик новых сообщений на аватаре слева; после прочтения пропадает. Закрепление сохранено, работает отдельно от открытия.
- В переписке спокойный фон, входящие/исходящие пузырьки, компактная шапка и ввод. Данные семьи, карточки детей, предложение дней ПУ и действия с открытым вопросом в меню «⋯». Канал ответа уже выбран, доступна явная смена. Голосовые, файлы, стикеры и скрипты сохранены.
- Черновики текста/файлов и неопределённой частичной отправки сохранены по каждому диалогу. Запоздавший GET не открывает предыдущий чат. Завершение отправки в старом чате не стирает новый черновик и не возвращает сотрудника обратно. Предложение ПУ и предупреждения карточки ограничены своим DOM-контекстом.
- У исходящего сообщения есть «Удалить» с обязательным подтверждением. Для подключённых через Wazzup Telegram/WhatsApp/MAX — официальный DELETE v3 по ID исходного сообщения из БД. Входящие, тестовые/неподтверждённые сообщения, архивный/отдельный бот и сообщения старше 24 часов не отправляют запрос удаления; причина доступна у неактивной кнопки. Решение о доступности также проверяет сервер, роль operator/admin.
- Удаление не равно локальному сокрытию: после ответа API показано «Удаление запрошено», после webhook `isDeleted=true` — «Сообщение удалено». При ошибке/потере подтверждения оригинал виден, есть предупреждение, автоматического повтора нет. Повтор принятого запроса не вызывает внешний API снова. Хранятся ID, исходный текст и аудит; удаление в мессенджере нельзя отменить. Подтверждение привязано к тому же диалогу. При склейке дублей состояние удаления переносится и не воскресает от старого эха.
- Памятка отработок: четыре пункта «Когда», «Условие», «На какой неделе», «Как записаться». Убраны технические пояснения учёта, повторы и точки в конце абзацев. Маркеры, отступ продолжения и промежутки между пунктами. Оплаченные две тренировки не требуют фактического посещения: в тексте указана оплата. Допуск, сроки и погашение пропусков не менялись. Новые текст/шаблон автоматически меняют отпечаток памятки; старый PNG блокируется до перерисовки.

## Проверки и ограничения

19 модулей: 15 основного набора связи/скриптов/вложений/расписания/расчётов и отдельно message_deletion (6), memo_refresh (5), makeup_policy и wazzup_no_bridge (6). JavaScript syntax, compileall, git diff --check. Тест идемпотентности, ошибки/потери подтверждения, прав/времени/входящих/каналов, привязки webhook и склейки дублей.

Полный локальный HTTP + Chromium с синтетической БД/провайдером: отмена подтверждения не вызывает API; подтверждение посылает DELETE точного сообщения один раз, показывает ожидание; клиентский PNG содержит четыре пункта без конечных точек. Визуально проверена полная памятка, без обрезки/наложений. Отдельные браузерные проверки 1440/390: две колонки/мобильный возврат, текст и PDF по разным чатам сохраняются, счётчик слева от имени, поздний ответ GET игнорируется, завершение отправки не стирает новый черновик, предложение ПУ в меню, отсутствие горизонтального переполнения/ошибок JS. Поле ввода на телефоне выше нижней навигации.

В рабочей CRM сообщения не отправлялись и не удалялись. Авторизованный вход/получение реального webhook пока недоступны; публикация статических файлов не подтверждает удаление у реального адресата. Автоцепочки, деньги и рабочие настройки не включались/не менялись. Публикация и SHA фиксируются отдельно после push.
