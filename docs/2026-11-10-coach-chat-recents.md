# Экраны тренеров, чаты и история клиентов

## Тренеры

Планер закрыт для всех тренеров, включая совмещение с промоутером. Задачи, назначенные руководителем или старшим администратором, остаются на экране смены; в филиалах с отчётом включаются в его шаг «Задания». В Небе задачи отмечаются выполненными прямо на дашборде.

В филиалах, содержащих «Небо» в названии, новые тренерские отчёты не создаются, тренеры не могут править и отправлять старые, напоминания о несданных отчётах не формируются. Сохранённая история не удалена. Чоботовская, Арктика и другие филиалы сохраняют отчёты. У тренера с несколькими филиалами список отчётов отбирается по каждому филиалу отдельно.

Для тренеров, закреплённых только за Небом (с учётом главного/помощника и будущих замен), меню содержит «Мой дашборд» и «Журнал». Дашборд показывает количество детей и мест, свои группы, конверсию пробных, продления, посещаемость, сегодняшние тренировки и назначенные задачи. Денежные разделы закрыты на сервере, денежные поля и телефоны удаляются из ответов. В день только небовских тренировок тренер с несколькими филиалами также получает облегчённый дашборд, а отчёты других филиалов сохраняются. Для всех тренеров структурированные телефоны и контакты клиентов удаляются из API-ответов.

## Чаты

Добавлены разделители дней: «Сегодня», «Вчера» и календарная дата. Метка дня закреплена внутри прокручиваемой ленты до перехода к следующему дню. Это работает в диалоге и ленте семьи, включая звонки. При автоматическом обновлении диалога чтение старых сообщений не сбрасывается в конец.

В обоих редакторах сообщения видны отдельные кнопки «Смайлы» и «Стикеры». Смайлик заменяет выделение/вставляется в место курсора. Шесть графических стикеров показаны миниатюрами. Они отправляются PNG-изображениями через поддержанные каналы; нативные наборы и анимация не подключены. Используется Twemoji, CC BY 4.0, как описано в 2026-11-09-ui-changes.md. Реальных сообщений при проверках не отправляли.

## Поиск клиентов

При фокусе на пустом поле появляется «Недавно открывали»: до восьми последних карточек. История хранится на сервере отдельно для пользователя; таблица содержит только ID пользователя, ID клиента и время. Названия и телефоны читаются из актуальных записей. Повторное открытие поднимает карточку вверх без дубля. Учитываются явно открытые диалоги привязанной семьи; фоновые обновления чата историю не меняют. Архивные клиенты не показываются. «Очистить» очищает только собственную историю. Тренерам и стажёрам эти маршруты недоступны.

Из подсказки под кнопкой принятия документов удалена фраза о запросе копии у руководителя. Тексты документов и сохранённые принятия не изменены.
