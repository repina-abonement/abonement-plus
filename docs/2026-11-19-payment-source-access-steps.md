# Подключение источников контроля оплат

## CRM-151 / CRM-164 — конкретные шаги по внешним доступам (19.11)

- **Правило работы:** при блокере самостоятельно исследовать решения и выполнять доступные действия. Для ручного включения Юлии давать конкретный маршрут, действие и ожидаемый результат. Это закреплено в AGENTS.md.
- **Сбер — проверенная инструкция:** СберБизнес → Все продукты и услуги → Сбербанк API → Sber API → Подключить → набор «Компаниям» → подписать заявление → активировать сервис. Если уже подключено, создать отдельный сервис CRM через «Добавить сервис», не менять существующую интеграцию 1С. Официальная документация указывает бесплатное подключение/использование Sber API. Коннектор своей организации не требует объявления CRM сторонней платформой.
- **Техническая часть Сбера остаётся:** серверный OAuth, mTLS сертификат, защищённый ввод реквизитов, только GET_STATEMENT_ACCOUNT и при необходимости GET_STATEMENT_TRANSACTION, выбор счетов и обновление доступа. Простая активация набора не подтверждает подключение CRM и не ограничивает права автоматически. Сертификат .p12/пароль и client_secret в чат не запрашивать. Необходимы учёт срока сертификата и ротации секрета.
- **ОФД:** базовое обслуживание и отдельный доступ к данным различаются. По ранее переданному отчёту базовое обслуживание оплачено, отдельная «Интеграция ОФД в 1С» истекла; конкретная связь этой лицензии с /v1/client/receipts остаётся неподтверждённой. Сначала спросить поддержку: какая лицензия открывает API собственной CRM для нужной ККТ и исторических чеков, активирует ли её продление текущий токен, какие альтернативы поддерживаются. После подтверждения активировать нужную услугу в ЛК → Сервисы и услуги → Интеграция ОФД в 1С, выбрать ККТ; не покупать повторно базовое обслуживание.
- **Исправлена диагностика:** 403 Kkt is not paid больше не называется неверным токеном. Общий 403 не выдаётся за обязательность оплаты. Код не включает печать, оплату услуг или изменение внешних доступов.
- **Проверяемый результат после активации:** без ручного запуска фоновые циклы читают источники, находят существующую проводку №11534 и чек по ФН/ФД/ФП; общий успех возможен только при подтверждении банка и ОФД. Публикация/авторизованный результат проверяются отдельно.

Источники: https://developers.sber.ru/docs/ru/sber-api/start/connect ; /start/overview ; /start/tls ; /start/oauth ; https://platformaofd.ru/baza-znaniy/kak-podklyuchit-servis-1c-integraciya/ . Резерв Сбера: автоматическая передача из уже действующего 1С:ДиректБанк, если он действительно подключён; наличие не подтверждено. Разовая выписка полезна для теста, но не заменяет автоматический контроль.
