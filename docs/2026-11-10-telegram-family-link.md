# Telegram в карточке семьи

Проверка кода обнаружила, что семейная лента выбирала переписки только по привязанной семье и номеру. Родитель с закрытым номером Telegram мог остаться вне карточки, даже когда диалог уже принят CRM.

Добавлена автопривязка при открытии карточки по однозначному нормализованному номеру, точному Telegram username из контакта родителя либо Telegram user ID из уже связанного чата/архива экспорта. Ник распознаётся в формате @name, t.me/name, telegram:name и tg:name. Совпадение имени человека не используется. Конфликтующие идентификаторы и неоднозначные совпадения не связываются. Ручная связь с другой семьёй не переопределяется. Удалена эвристика связывания неизвестного отправителя с единственным недавно начатым Telegram-диалогом по номеру.

Новая переписка обновляет список доступных мессенджеров, даже если в ней ещё нет сообщений. При перестроении блока сохраняется набранный текст; запоздавший ответ от другой карточки не подменяет текущую. Поле ввода увеличено отдельно.

Для семьи Миллера фактическая причина не подтверждена: нет доступа к рабочей переписке и нет ответа, видна ли она в «Чатах и звонках» CRM. Автопривязка не загружает историю личного Telegram, отсутствующую у подключённой интеграции. Реальные сообщения не отправлялись.
