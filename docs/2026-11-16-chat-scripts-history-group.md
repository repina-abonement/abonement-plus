## Ограничения

Публикация/публичные файлы рабочей CRM проверяются после push отдельным шагом. Применение настройки к фактической группе, сохранение приватных Telegram-приглашений и живое получение сообщения/стикера не подтверждаются локальными тестами. Для рабочего теста пользователь ранее разрешила только конкретную семейную карточку на свой контакт; перед отправкой нужно однозначно сверить получателя. Такой тест не выполнен: авторизованного браузера/SSH нет, TinyFish не запускает работу из-за отрицательного баланса; пополнение не выполнялось.

Скрин настроек подтверждает HTTP 403 моста Telegram с сервера CRM и отсутствие прямой сети. Источник проблемы allowlist/IP остаётся гипотезой. Оплаченная подписка Wazzup — подтверждённое сообщение пользователя, а не проверка канала. Добавлена отдельная read-only диагностика каналов Wazzup и разные подписи бот/Wazzup; без сохранения настроек, повторных отправок или смены адресата.
