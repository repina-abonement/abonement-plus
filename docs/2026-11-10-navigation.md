# Иерархия бокового меню

Группы бокового меню оформлены отдельными секциями: фон, рамка, выразительный заголовок и стрелка раскрытия. Подпункты сдвинуты вправо и объединены вертикальной линией. Основные пункты отделены от групп. Длинные подписи переносятся и не обрезаются. Обе темы оформления поддержаны. Кнопки групп сообщают состояние раскрытия для программ чтения с экрана.

Проверка Chromium на выдуманной базе: визуально просмотрены обе темы, раскрытие/сворачивание, переход к вложенному разделу и активный пункт. Ошибок JavaScript нет. Состав разделов и права пользователей не менялись.
