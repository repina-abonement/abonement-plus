## Изменения

- Кнопка «Написать в Telegram» для @username и t.me/username, включая мобильный экран
- Только открытие диалога: отправка остаётся отдельным действием сотрудника
- Wazzup v3 username вместо phone для ника, повторное открытие существующего однозначного чата того же рабочего канала
- Сохраняется подтверждённый chatId: следующие тексты, стикеры и файлы используют его вместо повторного поиска по телефону/нику
- При первом сообщении по телефону используется единственный известный чат того же канала; неоднозначность требует выбора
- Нет messageId — нет записи об успешной отправке текста/стикера
- Ошибка Telegram по телефону объясняется простыми словами, код и описание Wazzup сохраняются, API-ключ скрывается
- Автоматических повторных отправок и смены мессенджера/контакта нет
