# Настройки задачи в полной карточке

Под описанием и комментариями расположен свёрнутый блок «Настройки задачи». Поля: название, описание, дата, время, исполнитель, важность и повтор (без повтора, каждый день, неделю с выбором дней, месяц, год). Исполнителя может менять руководитель или старший администратор; остальные пользователи работают со своими задачами.

Для существующего повтора доступны «Только эта задача» и «Эта и будущие задачи». Повтор меняется во втором режиме. При смене режима серия разделяется с даты выбранной задачи: прошлые и выполненные записи сохраняются, будущие открытые экземпляры старой серии отменяются, действует новое расписание. При отключении повтора выбранная задача остаётся разовой. Исключение в одной задаче не создаётся повторно при следующем открытии планера. Автоматические задачи дня рождения и закрытые задачи не редактируются этой формой.

Проверки: tests.test_planner_edit — включение повтора, изменение серии, отключение, сохранность истории, исключение без дублей, права и ошибки входных данных. tests.test_trainee — HTTP чтение и правка своей задачи и отказ в назначении другому стажёру. Chromium — блок свёрнут по умолчанию, сохранение названия/времени, включение еженедельного повтора и отключение для будущих задач; ошибок JavaScript нет. Общие тесты имеют те же четыре ранее подтверждённые ошибки: test_coachreport, test_planner, test_pu, test_required.
