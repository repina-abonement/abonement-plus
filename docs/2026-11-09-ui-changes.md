## Ограничения интеграций

Wazzup: https://wazzup24.com/help/api-en/sending-messages/ документирует contentUri для вложений, отдельного метода нативных стикеров нет. Поэтому используются изображения PNG без анимации. Поддержка форматов зависит от канала.
MAX: https://dev.max.ru/docs-api/methods/POST/messages поддерживает image.payload.url, а нативные sticker требуют code. Каталог кодов стикеров в CRM не подключён. Текущий выбор отправляется как изображения.
Изображения: Twemoji (https://github.com/jdecked/twemoji), графика Twitter и участников проекта, CC BY 4.0 (https://creativecommons.org/licenses/by/4.0/). Используются публичные PNG v15.1.0. Доступ к raw.githubusercontent.com нужен провайдерам для загрузки картинки.
Реальные отправки не выполнялись: в среде нет ключей подключений.
