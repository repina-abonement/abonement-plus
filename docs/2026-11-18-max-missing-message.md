# CRM-153 — пропавшее входящее MAX

Ориентир пользователя: Руфина, 18.11.2026 12:55 МСК, сообщение видно в Wazzup, не видно/не ищется в CRM. MAX chatId из показанного URL: 181742783, канал: 2a291237-241a-4b14-a557-9b44a3e6a7e9. Номер 79916150960 в шапке относится к школе, не использовать как телефон клиента

Подтверждённые локальные дефекты: ошибка обработки Wazzup откатывалась с ответом HTTP 200; запоздалый ответ поиска мог перезаписать более свежий. Исправлены, но их связь с конкретным сообщением пока не доказана

25 серверных тестов и Chromium-тест гонки поиска пройдены. Отдельные существующие сценарии MAX и телефонного поиска пройдены. Все тестовые сообщения и БД синтетические. Клиенту ничего не отправлялось
