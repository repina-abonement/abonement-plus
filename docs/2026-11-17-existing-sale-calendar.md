# Календарь и оплата существующего абонемента — 17 ноября 2026

Календарь отсутствовал из-за раннего return в existing-ветке openSell. Добавлен режим просмотра сохранённых дат lesson_schedule/program_selection и исключений, с маркерами ПУ. При отсутствии сохранённого состава нет выдумывания исторического расписания. Кнопки оплаты продолжают ссылаться на существующий ID

Предупреждение включает месяц/группу и статус уже оформленного абонемента. Серверный запрет создания повторной продажи сохранён

Локальный Chromium: существующий абонемент показывает четыре отмеченных даты, исключённое ПУ 16.11, все галочки disabled; ошибка JS отсутствует. Отдельный HTTP/Chromium на свежей синтетической БД: существующий неоплаченный абонемент, card_branch, 5120, дата 16.11, ответ 200, один абонемент и один платёж. Это не подтверждает сохранение реального платежа пользователя и не устанавливает причину рабочего toast «Ошибка»

Добавлены HTTP-код для ответа без JSON error и постоянное сообщение ошибки в форме вместо одного исчезающего toast. Повторный запрос текущей формы сохраняет request_id. Модуль tests.test_sale_paid_date и node --check пройдены. Публикация фиксируется отдельно

Дополнительно: защита повторной продажи усилена до ребёнок + группа + месяц даже при двух записях enrollments. Проверена отдельным тестом, единственный абонемент сохраняется. Chromium: имитация пустого HTTP 503 сохраняет объяснение в форме; повтор использует тот же request_id, ответ 200, единственный платёж. Это не воспроизведение рабочего отказа
