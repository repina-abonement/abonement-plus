# Свои наборы стикеров

Меню «Стикеры» теперь загружает общие наборы команды. Руководитель может раскрыть «Добавить свой набор Telegram», вставить ссылку и импортировать набор. Ссылка на Footbolika_Olya подставлена как пример по запросу Юлии. Сам набор в рабочую базу в ходе разработки не импортирован: нужен подключённый Telegram-бот, импорт запускается из CRM руководителем.

Импорт использует официальный getStickerSet/getFile с уже сохранённым токеном бота. Медиа сохраняются в SQLite, токены не попадают в каталог и ссылки картинок. Существующие стикеры повторно не добавляются. Ограничения: до 120 стикеров, до 1 МБ на изображение. Анимации/видео требуют статичного превью для общего каталога.

Через Telegram-бота используется sendSticker по file_id, включая оригинальную анимацию. Через Wazzup и MAX используется ранее реализованный канал отправки изображения; для анимации — статичное превью. Поддержка WEBP зависит от провайдера и канала. Сквозная доставка реальным адресатам не проверялась, сообщения клиентам не отправлялись.

Проверка: test_sticker_packs проверяет импорт, дедупликацию, превью, отсутствие токена в каталоге, маршрутизацию TG/MAX на заглушках. Браузер проверил импорт ссылки, выбор своего стикера и передачу ID; прежняя проверка смайлов/даты/стикеров прошла. Общий прогон: прежние ошибки test_planner, test_pu, test_required.
