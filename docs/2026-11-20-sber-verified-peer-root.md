## CRM-151 / CRM-164 — ручное подключение Сбера отложено до утра (20.11)

- **Последнее решение Юлии:** продолжить утром. Юлия не помнит пароль СберБизнес, письмо восстановления на Gmail не приходит. Это отдельный блокер входа владельца; исправления серверного TLS не восстанавливают пароль.
- **Подтверждённое состояние:** успешное завершение нового OAuth, получение токенов и чтение рабочей выписки Сбера пока не подтверждены. Автоматический контроль всех оплат/зачислений/чеков остаётся незавершённым; прежние серверные изменения и локальные проверки сохраняются как отдельные результаты.
- **Напоминание:** по доступной подтверждённой сводке беседы отдельное напоминание создано на утро 21 ноября, около 08:00 МСК. В этом обновлении расписание не менялось; доставка напоминания ещё не проверялась.
- **Следующий шаг после паузы:** восстановить вход штатным способом СберБизнес. Если письмо по-прежнему не приходит, проверить адрес и папки Gmail, затем через официальный канал поддержки Сбера уточнить привязанный адрес и доступный способ восстановления. После входа — новый OAuth для отдельного сервиса CRM, проверенный ответ API и чтение выписки; далее сквозная проверка существующего №11534 и автоматических циклов. Состояние ОФД проверяется отдельно: оплата услуги сообщена, успешное чтение конкретного чека по API ещё не подтверждено.
- **Границы этого обновления:** документация актуализирована. Вход в банки, восстановление пароля, новые банковские проверки и рабочие финансовые операции не выполнялись; настройки CRM, фоновых циклов и напоминаний не менялись. Пауза относится к ручному продолжению подключения, а не к доказанной остановке серверных проверок.
