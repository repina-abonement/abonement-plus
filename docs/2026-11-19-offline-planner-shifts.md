# CRM-160 — утренняя и вечерняя смены общего планера

Юлия подтвердила две смены в понедельник и среду и разрешила реализацию для тестирования сотрудниками. Общий планер сохраняется. Варе доступны создание, редактирование, завершение/возврат, перенос и остановка повторов общего планера, как часть явно разрешённого управления этим функционалом. Доступ прочих старших/наблюдателей не расширен.

## Поведение

- В понедельник/среду блоки: утро (жёлтый), вечер (синий), общие задачи дня. Фильтр Все/Утро/Вечер; общие задачи видны в обеих сменах.
- При создании задачи на общий пул поле «Смена»: общая, утро, вечер, обе. В другие дни любая такая задача выполняется один раз как общая; это явно объяснено в форме.
- Режим обеих смен создаёт два разных tasks.id с независимыми отметками. Выполненная задача показывает автора и время отметки.
- Повторы хранят shift_mode, экземпляры tasks.shift. Уникальный auto_key включает смену; повторное generate/materialize не создаёт дубли.
- Старые задачи и повторы после миграции common; без угадывания названий/расписаний не меняются и не удваиваются. Для перенастройки Варя открывает задачу → настройки → Эта и будущие задачи → Обе смены → сохранить. Будущие открытые экземпляры заменяются, выполненная прошлая история остаётся.
- Одна задача повторяющейся серии может иметь своё исключение смены; настройка обеих смен требует области будущих повторов. У разовой задачи обе смены создают отдельную пару.
- Личные планеры не принимают сменные режимы; права проверены сервером. Доступ Вари основан на единственной активной учётной записи с ранее подтверждённым полным именем; дубликаты не угадываются.

## Проверки и граница результата

7 профильных серверных/HTTP тестов: независимое завершение, автор/время, понедельник и среда, вторник один раз, идемпотентные повторы, перенос настройки старой серии, прошлая выполненная история, чужие права, Варины права. Дополнительно существующие сценарии test_planner, test_planner_edit, test_planner_stop, test_offline_planner, test_offline_planner_existing, test_offline_planner_unified пройдены.

Реальный JS интерфейса в Chromium с синтетическим API: блоки и разные цвета, фильтр, сохранение общей задачи при фильтрации, автор/время выполнения, открытие формы плюсом нужной смены, отправка режима both с ID общей доски. Снимки desktop/mobile локальные, без рабочих данных.

Рабочие задачи не переводились между сменами этим изменением. Авторизованная проверка сотрудниками после обновления ещё требуется. Это функциональная доработка планера, не подтверждение переноса ERP и не завершение платёжных интеграций.
